# MeMyMyo

A personal Mac voice studio for narrating scripts and replacing individual sentences in a finished recording.

[MeMyMyo at Burrito’s Labs](https://memymyo.burritoslabs.com/)

## Technology

Native macOS audio workflows and on-device voice models on Apple silicon.

## Architecture

A project keeps the script and recorded performance together. A sentence can be re-recorded and auditioned in context while the rest of the recording is preserved.

## Product behavior

The core voice models are a separate download. The official product site carries current Mac requirements, installation and license details.
